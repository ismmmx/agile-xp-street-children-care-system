# Code of Conduct

## Our standard

This repository documents a university team project. While it is not an active open-source community, the team adopts the following standards for anyone interacting with this repository — team members and outside visitors alike — through issues, comments, or any future contributions.

We expect everyone to:

- Communicate respectfully and professionally, as in any academic or workplace setting.
- Give and accept constructive feedback gracefully.
- Focus on what is factually accurate and useful to the project and its documentation.
- Respect that this project concerns sensitive information about a vulnerable population (street children); no real child data, names, or identifying details should ever be posted here, in an issue, in a comment, or in a pull request.

We do not tolerate:

- Harassment, insults, or personal attacks directed at any team member or contributor.
- Discriminatory language or behavior of any kind.
- Sharing or requesting real, non-sample data about children, students, or any private individual in this repository.
- Public shaming of the team's academic work in bad faith; constructive critique is welcome, hostility is not.

## Scope

This applies within all spaces connected to this repository: issues, pull requests, discussions (if enabled), and commit messages.

## Reporting

If you have a concern about conduct in this repository, contact the project leader, Ishmam Mubtasim, through GitHub ([@ismmmx](https://github.com/ismmmx)).

## Attribution

This is a lightweight, project-specific code of conduct adapted for the scale and academic context of this repository. It does not claim to be a full community governance document.
