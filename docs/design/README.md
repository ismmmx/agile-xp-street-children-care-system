# UI/UX Design

**Figma project:** [Street_Children_Care_System](https://www.figma.com/design/SAj49Efd8CGjBv6D91nNh9/Street_Children_Care_System?node-id=9-36)

The interface is a dark-themed desktop UI with a persistent sidebar and role-specific dashboards, designed in Figma. The images below are exported prototype screens, not screenshots of the running application. All names, IDs and figures in the screens are illustrative sample data.
