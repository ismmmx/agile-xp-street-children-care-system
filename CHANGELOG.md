# Changelog

All notable changes to this repository are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions use [Semantic Versioning](https://semver.org/).

## [1.2.0] - Repository Governance Update

### Added
- `CONTRIBUTING.md` with branch, commit-message and pull-request conventions.
- `CODE_OF_CONDUCT.md` with team behavior standards.
- `.github/ISSUE_TEMPLATE/` with bug-report and documentation-suggestion templates.
- Table of contents, a "How to Use This Repository" section, and a Contact/Acknowledgements section in `README.md`.

### Changed
- `README.md` reorganized to follow a standard professional sequence (elevator pitch → table of contents → features → tech stack → methodology → structure → contributing → license → contact).
- Section headers given purposeful emoji anchors for quicker scanning.

## [1.1.0] - Portfolio Documentation Edition

### Added
- Project overview `README.md` with problem statement, roles, features, methodology, Git workflow, UI/UX design, testing and team contributions.
- `docs/` folder: project report (PDF), requirements summary, UI/UX design index, test cases, and project-management evidence.
- `assets/` folder: use case diagram, Figma screen exports, Git and Trello evidence images.
- MIT `LICENSE`, `.gitignore` and a pull request template.

### Changed
- Repository renamed from `project-simulator-team-3` to `agile-xp-street-children-care-system`.
- `PROJECT_FEATURES.md` moved to `docs/requirements/implemented-features.md`.

## [1.0.0] - Academic Submission Release

### Added
- Task-by-task feature log (T-1 to T-53) linked to the Trello board.
- Branch promotion workflow `dev` → `stage` → `main`, with release candidate (PR #58) and official release (PR #59).
